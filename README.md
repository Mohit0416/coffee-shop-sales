# coffee-shop-sales
📊 Coffee Shop Sales Dashboard.
Thrilled to share my latest Excel dashboard built around coffee shop sales data! ☕ Using Power Query, I performed comprehensive data cleaning—standardizing weekday and month formats, and extracting both month names and month numbers to enrich analysis.
🔍 This dashboard presents:
:- Sales insights across different store locations.
:- Footfall metrics and average bill per person.
:- Hourly order trends with peak insights.
:- Best-selling products visualized via bar charts.
:- Category-wise and size-wise order distributions.
:- Weekday performance comparison.
